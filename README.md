# RomanDigital

## Sobre o projeto

O RomanDigital é um sistema web desenvolvido como uma Prova de Conceito (PoC) para auxiliar na organização e no controle de pedidos, romaneios e entregas.

O objetivo é facilitar o acompanhamento dos pedidos e tornar o processo de distribuição mais organizado.

## Funcionalidades

- Cadastro de pedidos.
- Listagem de pedidos cadastrados.
- Atualização do status dos pedidos.
- Criação de romaneios.
- Seleção de pedidos para compor romaneios.
- Visualização dos pedidos vinculados a cada romaneio.
- Dashboard com indicadores de pedidos pendentes e entregues.

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript
- Node.js
- Express
- SQLite

## Como executar o projeto

1. Instale o Node.js.
2. Abra a pasta `backend` no terminal.
3. Instale as dependências com:

   npm.cmd install

4. Inicie o servidor com:

   node server.js

5. Abra o arquivo `frontend/index.html` com o navegador ou utilize a extensão Live Server do VS Code.
