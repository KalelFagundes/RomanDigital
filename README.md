
# RomanDigital

## Sobre o projeto

O RomanDigital é um sistema web desenvolvido como uma Prova de Conceito (PoC) para auxiliar na organização e no controle de pedidos, romaneios e entregas.

O objetivo é facilitar o acompanhamento dos pedidos e tornar o processo de distribuição mais organizado e eficiente.

## Funcionalidades

- Cadastro de pedidos.
- Listagem de pedidos cadastrados.
- Atualização do status dos pedidos.
- Criação de romaneios.
- Seleção de pedidos para compor romaneios.
- Visualização dos pedidos vinculados a cada romaneio.
- Dashboard com indicadores de pedidos pendentes e entregues.

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript
- Node.js
- Express
- SQLite

## Como executar o projeto

### Pré-requisitos

- Node.js instalado.
- Visual Studio Code (recomendado).

### Passo a passo

1. Faça o download ou clone este repositório.
2. Abra a pasta principal `RomanDigital` no Visual Studio Code.
3. Abra o terminal na pasta principal do projeto.
4. Instale as dependências:

   ```bash
   npm.cmd install
   ```

5. Entre na pasta do backend:

   ```bash
   cd backend
   ```

6. Inicie o servidor:

   ```bash
   node server.js
   ```

7. Abra o arquivo `frontend/index.html` utilizando o Live Server do VS Code.
